 Текущий алгоритм хранения Записей плана:

 1. При импорте предварительного плана все предыдущие Записи плана удаляются, включая те, что пришли с Сообщениями.
 2. После импорта утверждённого плана далее он не импортируется и не удаляется, из него берётся информация по Номенклатуре, где нет изменений.
 3. Далее Записи оперативного плана (на любые изменения) приходят только с Сообщениями, предыдущие Записи плана по этим Ном и Месяцу удаляются.
 4. До утверждения плана Записи оперативного плана не импортируются (принято решение, чтобы не было путаницы из-за параллельной выгрузки из предварительного и оперативного планов).
